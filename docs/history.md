## 三、值得留档的工程排查

### 1. 琴键无声四连修（09-08 ~ 09-09）
现象反复出现，最终定位三个叠加根因：
1. `PianoKeyboard` 是纯视觉组件，没有点击事件 → 补 pointer 交互
2. `handleNav` 里 `void Tone.start()` 不等待，Sampler 在 suspended 上下文里创建 → 改 `await`
3. Tone.js 模块加载时 `enforceLowLatency()` 提前创建了 suspended AudioContext；且 `Tone.start()` 对 DummyContext 是空操作 → 改为首次用户手势时 `Tone.getContext()` + `Tone.start()`（`ensureAudioUnlocked`）
另发现残留 `engineRef` 导致自由弹奏误走对错判定分支，一并清理。

### 2. OMR 大图像素上限（09-07）
3809×5387 ≈ 2050 万像素超过 Audiveris 2000 万硬上限（`Too large image`）→ 识别前检测像素数，超限等比缩到 1900 万以内（`MAX_PIXELS`），并给友好错误提示。

### 3. 上升音块几何三次迭代（09-10）
长按音符的音块会盖住先前短音块。方案演进：
1. 钳制顶边（被用户否决：音块被截断，两者不独立）
2. 分层绘制（长音在下短音在上，仍会视觉吞并）
3. **时间映射几何**（最终）：顶边 = 开始时刻位置、底边 = 结束时刻位置，两边同速上升，后按音块的顶边永远在先前音块底边之下，从数学上不可能重叠。

### 4. 成就弹窗双 bug（09-10）
- 不消失：计时器与显示写在同一个 effect，`setVisible` 触发重渲染时 cleanup 取消了刚设的定时器 → 拆成两个 effect，计时器只依赖 `visible`。
- 重复触发：事件回调闭包里的 `gamification` 永远是最初状态 → 改用 `gamificationRef` 始终读最新值，并对弹窗队列按 id 去重。

### 5. 随机端口吞掉 localStorage（09-10）
桌面版每次启动用随机端口起本地服务，origin（协议+主机+端口）每次都变，localStorage 等于全新空间，课程进度/成就全部"丢失"。改为固定端口 47823（占用时退回随机）。

### 6. Windows 打包无需 wine（09-10）
electron-builder 26 已不需要 wine，在 macOS 上可直接产出 Windows 安装包。Audiveris 官方只发 MSI，用 `pymsi` 解析 MSI 文件表 + `7zz` 提取 CAB 载荷，按 Directory/Component 表链重建出完整应用目录（2707 文件含 JRE），实现了在 macOS 上组装 Windows 引擎。
