# Piano Studio UI · 2026-09-22

## 市场学习与取舍

参考 flowkey 的官方产品介绍（https://www.flowkey.com/）：课程、曲目发现、等待式与即时反馈是主要入口。应用到本项目：把“下一课”设为学习页主要操作；曲库独立提供搜索与来源筛选；保留原有等待式和自由式。

同时检索了 Playground Sessions（https://www.playgroundsessions.com/）和 ROLI 的钢琴学习资料（https://roli.com/blog/what-is-the-best-piano-learning-app）。这些站点在当前浏览器中加载受限，没有据此声称做过完整产品体验或字体测量。

本轮配色、字体和版式为原创设计取舍：暖白纸面、墨绿文字、低饱和单元色；演奏使用深色。未复制商业产品图片、商标或页面素材。

## 设计与实现

- 字体：本地 Inter 400/500/600/700 拉丁子集，中文回落苹方或微软雅黑。无需在线字体服务。
- 首页：下一课主卡、CSS 琴键插画、五单元课程列表；区分当前课、可复习课和未解锁课。
- 曲库：原创乐谱封面、搜索、全部/内置/我的乐谱筛选、搜索无结果状态；自定义曲目删除增加确认步骤。
- 导航：品牌、页面选中状态、设备信息、等级、打卡；窄屏导航换行。
- 成长：等级进度、四项真实数据、成就卡片。没有新增模拟统计或图表。
- 导入：按图片/PDF 与 MIDI 区分入口；简化文案，保留文件处理与校对流程。
- 课程/报告/编辑器：继承暖色设计令牌。演奏和自由弹奏保持深色，复用原有音频与判定逻辑。

主题样式在 src/studio.css；语义变量只在 .studio 容器中覆盖。后续调整应优先修改语义令牌和组件类，避免直接覆盖全站通用元素。
